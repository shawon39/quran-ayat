# কনটেন্ট গাইড — একটি আয়াত কীভাবে লিখতে হয়

প্রতিটি আয়াত `content/verses/<সূরা>-<আয়াত>.json` ফাইলে থাকে, দুটোই তিন অঙ্কে —
যেমন `002-255.json`, `013-028.json`, `114-001.json`।

`data/verses.json` **নিজে সম্পাদনা করবেন না** — সেটি `scripts/build-content.mjs` তৈরি করে।

---

## কাজের ধাপ

1. `node scripts/fetch-sources.mjs <সূরা> <আয়াত>` — আরবি পাঠ, তিনটি বাংলা অনুবাদ,
   দুটি ইংরেজি অনুবাদ, পাঁচটি তাফসীর এবং **তিলাওয়াতের ঠিকানা** একসাথে দেখায়।
2. অন্তত **দুটি স্বতন্ত্র তাফসীরে** মিলিয়ে ব্যাখ্যা লিখুন। মতভেদ পেলে দুটোই লিখুন।
3. হাদীস উদ্ধৃত করলে **সংকলনের নাম ও নম্বর** দিন, এবং সেটি sunnah.com-এ মিলিয়ে নিন।
4. `node scripts/validate-content.mjs` → `node scripts/build-content.mjs`।
5. **তিলাওয়াত বাজিয়ে দেখুন** — নতুন আয়াতের পাতায় গিয়ে প্লে বোতামে চাপ দিন,
   আর শুনে নিশ্চিত হন যে ঠিক ওই আয়াতটিই বাজছে (নিচে দেখুন)।

## ক্ষেত্রগুলো

### বাধ্যতামূলক

| ক্ষেত্র | ধরন | কী লিখবেন |
|---|---|---|
| `surah` | সংখ্যা ১–১১৪ | সূরা নম্বর |
| `ayah` | সংখ্যা | আয়াত নম্বর |
| `arabic` | লেখা | উসমানী লিপিতে মূল পাঠ — `fetch-sources` থেকে হুবহু কপি |
| `uccharon` | লেখা | বাংলা উচ্চারণ। দীর্ঘ স্বর `-` দিয়ে, যেমন `আল্লা-হু লা- ইলা-হা` |
| `summary` | লেখা | এক-দুই বাক্যে আয়াতটি কী বলছে |
| `translations` | তালিকা, **অন্তত ২টি** | `{ by, source, text }` — অনুবাদকের নাম, প্রকাশক, হুবহু অনুবাদ |
| `sections` | তালিকা, অন্তত ১টি | `{ heading, body: [অনুচ্ছেদ, …] }` — মূল ব্যাখ্যা |
| `lessons` | তালিকা, **অন্তত ২টি** | মূল শিক্ষা, এক বাক্যে করে |
| `application` | তালিকা, **অন্তত ২টি** | বাস্তব জীবনে কীভাবে কাজে লাগে |
| `tags` | তালিকা, অন্তত ১টি | বিষয় — `তাওহীদ`, `ধৈর্য`, `যিকির`, `পরিবার` … |
| `sources` | তালিকা, **অন্তত ২টি** | `{ label, url }` — যেগুলো থেকে যাচাই করা হয়েছে |
| `verifiedOn` | `YYYY-MM-DD` | যেদিন যাচাই করা হলো |

### ঐচ্ছিক

| ক্ষেত্র | কী লিখবেন |
|---|---|
| `title` | আয়াতটির প্রচলিত নাম, থাকলে — যেমন `আয়াতুল কুরসী` |
| `ayahEnd` | ধারাবাহিক কয়েকটি আয়াত একসাথে হলে শেষ আয়াত নম্বর |
| `words` | `{ ar, bn, note }` — শব্দে শব্দে অর্থ |
| `hadith` | `{ text, source }` — `source`-এ সংকলন ও নম্বর বাধ্যতামূলক |
| `related` | `{ ref, surah, ayah, note }` — সম্পর্কিত আয়াত |
| `addedOn` | `YYYY-MM-DD` — “সাম্প্রতিক সংযোজন”-এর ক্রম এতে ঠিক হয়, আর সবগুলোর মধ্যে সবচেয়ে নতুন তারিখটিই ফুটারে “সর্বশেষ হালনাগাদ” হিসেবে দেখায় |

## তিলাওয়াত — নতুন আয়াত যোগ করার সময় যা করতে হয়

অডিওর জন্য JSON-এ **কোনো ক্ষেত্র লিখতে হয় না**। ক্বারী মিশারী রাশিদ আল-আফাসীর তিলাওয়াত
`surah` ও `ayah` থেকেই আপনাআপনি বেরিয়ে আসে (`assets/js/audio.js`)। কিন্তু ফাইলটি লেখা শেষ
হলে **প্রতিবারই শুনে যাচাই করা বাধ্যতামূলক** — অনুবাদ যেমন মিলিয়ে দেখা হয়, তিলাওয়াতও তেমনি।

1. `node scripts/fetch-sources.mjs <সূরা> <আয়াত>` চালালে শেষে তিলাওয়াতের দুটি ঠিকানা দেখায় —
   একটিতে চাপ দিয়ে শুনে নিন, ওই আয়াতটিই কি না।
2. বিল্ডের পর `npm run dev` চালিয়ে `#/ayat/<সূরা>/<আয়াত>` পাতায় গিয়ে প্লে বোতামে চাপ দিন।
   সবুজ বারটিতে সময় এগোতে থাকলে ও কণ্ঠ শোনা গেলেই হলো।
3. `ayahEnd` দিলে **প্রতিটি** আয়াত পরপর বাজে — শুরু থেকে শেষ পর্যন্ত শুনে দেখুন, ফাঁক আছে কি না।
   `ayah` ও `ayahEnd` অবশ্যই ওই সূরার মোট আয়াতের ভেতরে থাকতে হবে;
   `validate-content.mjs` এটি ধরে ফেলে।
4. “অডিও আনা গেল না” দেখালে ইন্টারনেট সংযোগ দেখুন। সংযোগ ঠিক থাকা সত্ত্বেও একই আয়াতে
   বারবার এলে দুটি উৎসেই ফাইলটি নেই — README-র *তিলাওয়াত* অংশে ঠিকানার গড়ন দেওয়া আছে।

## লেখার ধরন

- **ভাষা বাংলা, সহজ ও সরাসরি।** পাঠক আলিম নন — পরিভাষা এলে পাশেই অর্থ বলে দিন।
- **অনুবাদ হুবহু।** `translations[].text` কখনো নিজে বদলাবেন না। যাকারিয়া সাহেবের অনুবাদে
  `[১]`, `[২]` ধরনের টীকা-চিহ্ন থাকলে সেগুলো তুলে দিন, বাকিটা অপরিবর্তিত।
- **দাবি করলে সূত্র দিন।** “অধিকাংশ মুফাসসির বলেছেন” লিখলে কোন তাফসীর, তা `sources`-এ থাকতে হবে।
- **মতভেদ লুকাবেন না।** একাধিক মত থাকলে দুটোই লিখুন, কোনটি বেশি শক্তিশালী তা বলুন,
  আর যেটিতে সবাই একমত সেই মূল কথাটি স্পষ্ট করে দিন।
- **ফযীলত সাবধানে।** দুর্বল বা জাল বর্ণনা এড়িয়ে চলুন; সহীহ/হাসান হলে তা উল্লেখ করুন।
- **বাড়াবাড়ি নয়।** আল্লাহর সিফাত সংক্রান্ত আয়াতে কুরআন-হাদীসে যতটুকু এসেছে ততটুকুই লিখুন।

### সীমিত মার্কআপ

`summary`, `sections[].body`, `lessons`, `application`, `hadith[].text`-এ দুটি চিহ্ন কাজ করে:

- `**গাঢ়**` → **গাঢ়**
- `*হেলানো*` বা `_হেলানো_` → _হেলানো_ (দুটোই কাজ করে)

এর বাইরে HTML লেখা যাবে না — নিরাপত্তার জন্য সব লেখা escape করে দেখানো হয়।

## `sections`-এর যে শিরোনামগুলো সাধারণত ব্যবহার হয়

ক্রম রাখলে পড়তে সুবিধা হয়:

1. **কোথায়, কেন এই আয়াত** — নাযিলের প্রেক্ষাপট, আগে-পরের আয়াতের সাথে সম্পর্ক
2. **বাক্যে বাক্যে অর্থ** — আয়াতটি টুকরো করে ব্যাখ্যা
3. **বিষয়ভিত্তিক শিরোনাম** — যেমন `‘কুরসী’ মানে কী`, `‘সবর’ বলতে কী বোঝায়`
4. **একটি সতর্কতা** — আয়াতটির প্রচলিত ভুল প্রয়োগ থাকলে
