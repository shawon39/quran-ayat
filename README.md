# আয়াত · Quran Ayat

কুরআনের গুরুত্বপূর্ণ আয়াতসমূহের **নির্ভরযোগ্য বাংলা অর্থ ও বিস্তারিত ব্যাখ্যার** একটি সংগ্রহ।
সম্পূর্ণ কুরআন নয় — বাছাই করা আয়াত, প্রতিটির সাথে শব্দে শব্দে অর্থ, নাযিলের প্রেক্ষাপট,
ব্যাখ্যা, মূল শিক্ষা, বাস্তব প্রয়োগ এবং প্রামাণ্য সূত্র।

**সাইট:** https://shawon39.github.io/quran-ayat/

---

## যা আছে

| | |
|---|---|
| ভাষা | সম্পূর্ণ বাংলা (আরবি মূল পাঠ ছাড়া) |
| থিম | কেবল লাইট মোড |
| তিলাওয়াত | ক্বারী **মিশারী রাশিদ আল-আফাসী**-র কণ্ঠে প্রতিটি আয়াতের অডিও, সাথে বারবার বাজানোর সুবিধা |
| খোঁজা | সূরার নাম, `২:২৫৫` ধরনের নম্বর, কিংবা অনুবাদ/ব্যাখ্যার যেকোনো শব্দ |
| চলাচল | ১১৪টি সূরার তালিকা → সূরা → নির্দিষ্ট আয়াত নম্বরে সরাসরি যাওয়া |
| প্রিয় | তারকা চিহ্নে সংরক্ষণ, ব্রাউজারেই (`localStorage`) — কোথাও পাঠানো হয় না |
| নির্ভরতা | কোনো ফ্রেমওয়ার্ক নেই, বিল্ড স্টেপ নেই — স্ট্যাটিক HTML/CSS/JS |

কি-বোর্ড: `/` চাপলে খোঁজার ঘরে যায়, `Esc` চাপলে বেরিয়ে আসে।

## ফোল্ডার

```
index.html               পাতার খোলস
assets/css/styles.css    পুরো সাইটের স্টাইল (লাইট মোড)
assets/js/
  app.js                 রাউটিং, ইভেন্ট, শুরু করার কাজ
  views.js               প্রতিটি পাতার HTML
  search.js              খোঁজার যুক্তি ও হাইলাইট
  audio.js               তিলাওয়াত — অডিও বাজানোর যুক্তি
  data.js                JSON লোড ও সূচি তৈরি
  store.js               প্রিয় তালিকা (localStorage)
  util.js                বাংলা সংখ্যা, escape, ছোট সহায়ক

content/verses/*.json    ★ লেখার একমাত্র উৎস — এক আয়াত, এক ফাইল
data/verses.json         GENERATED — হাতে সম্পাদনা করবেন না
data/surahs.json         GENERATED — ১১৪টি সূরার তথ্য

scripts/
  fetch-sources.mjs      একটি আয়াতের সব প্রামাণ্য উৎস এক জায়গায় আনে
  validate-content.mjs   প্রতিটি আয়াত-ফাইলের গঠন পরীক্ষা
  build-content.mjs      content/ → data/verses.json
  build-surahs.mjs       data/surahs.json তৈরি
```

## নতুন আয়াত যোগ করা

```bash
# ১) সব প্রামাণ্য উৎস এক জায়গায় দেখুন
node scripts/fetch-sources.mjs 2 255

# ২) content/verses/002-255.json লিখুন  (docs/CONTENT-GUIDE.md দেখুন)

# ৩) গঠন পরীক্ষা ও বিল্ড
node scripts/validate-content.mjs
node scripts/build-content.mjs

# ৪) দেখে নিন
python3 -m http.server 8080     # → http://localhost:8080
```

ফাইলের নাম সবসময় `<সূরা ৩ অঙ্ক>-<আয়াত ৩ অঙ্ক>.json` — যেমন `002-255.json`, `013-028.json`।

## তিলাওয়াত (অডিও)

প্রতিটি আয়াতের পাতায় আরবি পাঠের নিচে একটি প্লেয়ার থাকে — ক্বারী **মিশারী রাশিদ আল-আফাসী**
(مشاري راشد العفاسي), মুরাত্তাল, হাফস ‘আন ‘আসিম, ১২৮ kbps। পাশের বোতামে একই আয়াত বারবার
বাজানো যায় (মুখস্থ করার জন্য), আর আয়াত-পরিসর হলে একটির পর একটি আপনাআপনি চলে।

রিপোজিটরিতে কোনো অডিও ফাইল রাখা হয়নি — দুটি প্রকাশ্য উৎস থেকে সরাসরি বাজে, প্রথমটিতে
না মিললে দ্বিতীয়টিতে নিজে থেকেই চেষ্টা করা হয়:

| উৎস | ঠিকানার গড়ন |
|---|---|
| আল-কুরআন ক্লাউড (`cdn.islamic.network`) | `…/quran/audio/128/ar.alafasy/<ধারাবাহিক আয়াত নম্বর>.mp3` |
| এভরিআয়াহ (`everyayah.com`) | `…/data/Alafasy_128kbps/<সূরা ৩ অঙ্ক><আয়াত ৩ অঙ্ক>.mp3` |

ধারাবাহিক আয়াত নম্বর (১–৬২৩৬) `data/surahs.json`-এর আয়াত-সংখ্যা থেকে ব্রাউজারেই হিসাব হয়।
অন্য ক্বারী যোগ করতে বা বদলাতে `assets/js/audio.js`-এর `RECITER` ও `CDN` — এ দুটোই যথেষ্ট।

## যাচাইয়ের নিয়ম

কোনো ব্যাখ্যা তখনই যোগ করা হয় যখন **অন্তত দুটি স্বতন্ত্র প্রামাণ্য উৎসে** তা মিলে যায়।
`validate-content.mjs` এটি বাধ্যতামূলক করে — দুটির কম অনুবাদ বা দুটির কম সূত্র থাকলে বিল্ড ব্যর্থ হয়।

ব্যবহৃত উৎস:

- **আরবি মূল পাঠ** — উসমানী লিপি, কিং ফাহাদ কুরআন মুদ্রণ কমপ্লেক্স-অনুমোদিত পাঠ
- **বাংলা অনুবাদ** — ড. আবু বকর মুহাম্মাদ যাকারিয়া (কিং ফাহাদ কমপ্লেক্স), মুহিউদ্দীন খান, জহুরুল হক
- **তাফসীর** — ইবনে কাসীর, ফাতহুল মাজীদ, আল-মুখতাসার, আসবাবুন নুযূল (আল-ওয়াহিদী)
- **হাদীস** — সহীহ বুখারী, সহীহ মুসলিম প্রভৃতি, নম্বরসহ

মতভেদ থাকলে সেটিও লিখে দেওয়া হয় — এক পক্ষকে একমাত্র মত হিসেবে দেখানো হয় না।
